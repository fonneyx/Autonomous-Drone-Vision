# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead: the
**Security** tab, then **Report a vulnerability**.

Relevant issues include:

- ways to send commands to the drone without passing the arbiter or the safety shield
- ways to make the system follow a target that is not allowed
- unauthenticated access to the backend API or the live video
- leaks of recorded personal data (operator profiles, video)

You will get a reply within 7 days.

## Supported versions

Only the latest release and `main` get fixes.
