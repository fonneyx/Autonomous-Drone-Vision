================================================================================
                          REINFORCEMENT LEARNING
================================================================================

ENVIRONMENT SPECIFICATIONS:

Name: DroneAvoidanceEnv
Framework: Gymnasium (OpenAI standard)

Observation Space (32 continuous values in [-1, 1]):
  - 5 obstacles x 6 features each:
    [x_center, y_center, width, height, confidence, class_id]
  - 2 drone state features:
    [forward_velocity, yaw_angle]

Action Space (2 continuous values):
  - action[0]: yaw_rate      [-1, 1] -> maps to [-45°/s, +45°/s]
  - action[1]: velocity      [0, 1]  -> maps to [0, 15] m/s

Reward Function:
  +1.0   = Each step forward without collision
  -100.0 = Collision with obstacle detected
  -5.0   = Penalty for erratic steering

Episode Configuration:
  - Max steps: 500 per episode
  - Collision threshold: normalized bbox area > 0.3
  - 5 obstacle tracking capacity

Integration: DroneDetectionWrapper converts YOLO detections to RL input

================================================================================
                          TRANSFER LEARNING DETAILS
================================================================================

WHY TRANSFER LEARNING IS IMPORTANT:
  1. Pre-trained backbone saves training time
  2. ImageNet features applicable to object detection
  3. Reduces overfitting on smaller datasets
  4. Better generalization to new classes

FREEZE PARAMETER (freeze=10):
  - Freezes first 10 layers of YOLOv11s backbone
  - Prevents modification of pre-trained weights
  - Only trains the detection head + neck
  - Optimal for 14-class custom dataset

LEARNING RATE (lr0=0.001):
  - Standard default: 0.01 (too aggressive)
  - Custom multi-dataset: 0.001 (stable)
  - Prevents catastrophic forgetting
  - Allows fine-tuning without disrupting backbone

CHECKPOINT RESUMPTION (exist_ok=True):
  - Allows resuming from previous runs
  - Accumulates learning across epochs
  - No need to restart training
  - Perfect for iterative refinement

RESULT:
  - 100 epochs training: ~2-3 hours
  - Expected mAP@50: 0.70-0.78
  - Model size: ~12 MB (YOLOv11s)
  - Inference speed: 30-40 ms/frame (GPU)
